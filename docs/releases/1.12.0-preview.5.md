# 1.12.0-preview.5 — Claude manual-reset availability

Bug fix within the existing manual-reset preview feature. The preview sequence advances; this does not introduce a new feature or change released versions.

- Working Claude Code quota no longer prevents a missing manual-reset inventory from being read through the existing Claude desktop web session.
- Reset offers are supplemented only when both measurements belong to the same Claude organization. Current OAuth limits and a reported zero inventory retain their meaning; an unavailable optional source does not discard working limits.

Verified: the same-organization regression fails before the fix and passes afterward. Eight source-selection scenarios cover matching, mismatching and unknown organization identity, unavailable/error sources, a reported zero, desktop-cache precedence and missing OAuth organization. The existing manual-reset renderer and expiry/privacy checks, Claude OAuth tests and full `npm run check` pass. The Docker image rebuild and isolated Compose startup/API smoke pass; the Node 22 container also preserves the supplemented reset through public probe normalization. Independent delta review passed.

The existing Claude desktop session is still required when OAuth and the desktop cache do not report reset offers. This change does not add browser-cookie extraction or a new sign-in flow. The reporting device's installed build, session availability and visible result remain unverified.

This is a CI review build. Publishing a GitHub release is a separate action.
