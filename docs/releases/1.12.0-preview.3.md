# 1.12.0-preview.3 — Consistent reset availability and local times

Fixes within the manual-reset preview feature; the preview sequence advances without adding a new feature version.

- The Codex provider card now uses the same account-scoped reset-credit inventory as the existing reset history, including each reported expiry. Missing expiry details remain unknown, and a reported zero stays distinct from unavailable data.
- Manual-reset expiry and observation times use the dashboard's existing local date/time formatter, matching the reset history and the selected language. The separate GMT-offset formatting is removed.
- Reset-credit labels are translated in every supported language. Provider account and credit identifiers are excluded from the shared display data.

Verification: focused inventory, privacy, account-response replacement, missing/zero/partial data, local-time consistency and translation tests; complete `npm run check` passed. Docker image rebuild and isolated Compose startup/API smoke passed. Browser verification of the actual card renderer showed all three Codex credits with the reported expiry dates, and the Claude expiry in the same local format as the existing history.
